Deployability

Every per-period figure on this page is a mean over overlapping forecast periods, and a portfolio cannot hold an overlapping period. The strategy signals daily and holds five days, so what it trades is five overlapping tranches: one fifth of capital rebalances into each day's targets. That construction holds every phase at once and has no free parameters.

Every model module set train_size = 3. That parameter counts trading dates, not blocks of dates, so each walk-forward window fitted 99 features on about 90 rows. The value was duplicated across five modules and was never revisited as the dataset grew. It is now DEFAULT_TRAIN_SIZE = 63, defined once.

Why the training window is 63 dates

Five window sizes were measured on an identical set of 223 evaluation dates. The relationship is an inverted U, not monotonic: Rank IC peaks at 21 dates and collapses to roughly zero at 252, which is what one would expect if long windows average across market regimes that no longer apply.

What did not improve

  • A one-feature momentum baseline still beats every trained model — 0.002264 against 0.001992. Narrowed, unresolved.
  • The 10-day horizon Rank IC fell from 0.039083 to 0.037407.
  • Margins remain thin. The most conservative portfolio configuration clears cost at a diagnostic Sharpe of 0.004.
  • Concentration still reduces performance, which is what a weak ranking signal looks like.
  • Foreign buy/sell features remain unpromoted. Pre-registered test: mean Rank-IC difference −0.002608, 95% CI [−0.013314, +0.008297]. The interval spans zero and the point estimate is negative.
Multiple comparisons. The training window was chosen by measuring five values against the same history, on top of three horizons, five ablation configurations, four optimizer modes, two execution modes and five foreign-flow feature sets already tested against it. The improvement is consistent across horizons, ablations and portfolio modes, which makes selection noise unlikely — but no confidence interval supports that, and no figure above carries one except the foreign-flow test.
