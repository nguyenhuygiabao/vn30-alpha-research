Headline

Every model module set train_size = 3. That parameter counts trading dates, not blocks of dates, so each walk-forward window fitted 99 features on about 90 rows. The value was duplicated across five modules and was never revisited as the dataset grew. It is now DEFAULT_TRAIN_SIZE = 63, defined once.

The core finding did not change. A single-feature momentum rule still beats every trained model. The gap narrowed from 1.6× to 1.14×, so part of it was undertraining — but not all of it. Nothing here supports an alpha claim.

Why 63 dates

Five training-window sizes were measured on an identical set of 223 evaluation dates. The relationship is an inverted U, not monotonic: Rank IC peaks at 21 dates and collapses to roughly zero at 252, which is what one would expect if long windows average across market regimes that no longer apply.

Paper-horizon predictions rebuilt

Separate from the training-window change. paper_horizon_predictions.parquet had been built from the static 30-ticker universe, so it contained predictions for names on dates they were not index constituents. Under point-in-time filtering those rows correctly vanish, and only fully covered dates survive — which left two scripts reporting on three observations.

What did not improve

  • A one-feature momentum baseline still beats every trained model — 0.002264 against 0.001992. Narrowed, unresolved.
  • The 10-day horizon got marginally worse on Rank IC (0.0391 → 0.0374) and on top-5 hit rate.
  • Margins remain thin. The most conservative portfolio configuration clears cost at a diagnostic Sharpe of 0.004.
  • Concentration still reduces performance, which is what a weak ranking signal looks like.
  • Foreign buy/sell features remain unpromoted. Pre-registered test: mean Rank-IC difference −0.002608, 95% CI [−0.013314, +0.008297]. The interval spans zero and the point estimate is negative.
Multiple comparisons. This parameter was chosen by measuring five values against the same history, on top of three horizons, five ablation configurations, four optimizer modes, two execution modes and five foreign-flow feature sets already tested against it. The improvement is consistent across horizons, ablations and portfolio modes, which makes selection noise unlikely — but no confidence interval supports that judgement, and none of the figures above carry one except the foreign-flow test.
